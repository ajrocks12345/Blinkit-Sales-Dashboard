# Blinkit Sales Dashboard (Power BI)

An interactive Power BI dashboard analyzing retail sales performance across outlets for Blinkit ("India's Last Minute App"). This was my first-ever Power BI project, built while learning the tool, and later revisited for GitHub.

## Overview

The dashboard provides a 360° view of sales performance across outlets, item categories, and locations, with fully interactive filtering.

## Key Features

- **KPI Summary Cards** — Total Sales, Average Sales, No. of Items, and Average Rating
- **Outlet-wise Breakdown** — Sales performance segmented by:
  - Location Tier (Tier 1 / Tier 2 / Tier 3)
  - Outlet Size (High / Medium / Small)
  - Outlet Type (Supermarket Type1/Type2, Grocery Store)
- **Item Type Analysis** — Sales split across 16 item categories (Fruits & Vegetables, Snack Foods, Household, Frozen Foods, Dairy, etc.)
- **Fat Content Analysis** — Low Fat vs. Regular product split, overall and by outlet tier
- **Outlet Establishment Trend** — Sales trend across outlets established from 2012–2022
- **Interactive Filter Panel** — Slice data by Outlet Location Type, Outlet Size, and Item Type
- **Toggle View** — Switch the outlet chart between Total Sales, Avg Sales, No. of Items, and Avg Rating

## Tools Used

- **Power BI Desktop** — data modeling, DAX measures, report design
- **Power Query (M)** — data cleaning and transformation

## Dashboard Preview

The dashboard includes:
